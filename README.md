# AccessVault

Sistema web de gestão de acessos, credenciais e solicitações internas para empresas e equipes.

## Objetivo
Centralizar o controle de acessos a sistemas internos, permitindo visualizar quem tem acesso a quê, registrar solicitações, aprovações, revogações e manter histórico de ações.

## Escopo inicial
- autenticação
- usuários
- sistemas
- acessos
- solicitações
- dashboard
- gerador de senhas
- histórico de ações

## Stack planejada
- Frontend: HTML, CSS e JavaScript
- Backend: Python + FastAPI
- Banco de dados: SQLite
